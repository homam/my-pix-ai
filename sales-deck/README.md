# MyPix AI — Sales Deck

A self-contained, single-file HTML slide deck for selling MyPix AI. No build step, no dependencies.

## View it
Open `index.html` in any browser (or just preview it).

- **← / →** (or Space / PageDn) — navigate slides
- **F** — toggle fullscreen
- **Home / End** — jump to first / last slide
- Swipe left/right on touch devices
- On-screen ‹ › buttons + progress bar + slide counter

## Export to slides / PDF
`Cmd/Ctrl-P` → **Save as PDF**. Print CSS renders one slide per page at 1280×720, colors preserved (enable "Background graphics"). The PDF imports cleanly into Keynote, PowerPoint, or Google Slides.
